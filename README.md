In Pursuit is a high-adrenaline, 2D police getaway game where every second you survive ramps up the chaos. Cops not only give chase, they swarm, crash, and explode. Use their aggression against them by baiting collisions. Each hit chips away at your health and when it’s gone, it’s game over.

Powerups like Oil Slick, Nitro, Shield, Magnet, and Mystery Box keep you in the fight. Near misses fuel your Rage Mode, making you indestructible for a set time. 

Earn money by blowing up cops, unlock faster cars, and survive longer with skill and strategy.
